GRIND RINGS ACTION TRACKER
==========================

Tracker pentru actiunile de la rectificarea inelelor. Server propriu, independent,
pe portul 8092. Datele sunt intr-o baza de date proprie (grind_rings.db).
Nu are nevoie de Excel, de internet sau de alt server - doar de Python 3
(https://www.python.org/downloads/ , cu bifa "Add python.exe to PATH").
Python poate fi si direct in folderul tracker-ului (ex. GrindRingsTracker\python\python.exe,
versiunea "embeddable" de pe python.org) - instalarea il gaseste singura si il foloseste.

  Tracker:  http://NUME-CALCULATOR:8092/
  Grafice:  http://NUME-CALCULATOR:8092/grafice
  Setari:   http://NUME-CALCULATOR:8092/setari   (conturi, email, contul meu)


CE CONTINE O ACTIUNE
--------------------
Nr, Data, Masina / Linie, Reper (cod inel), Comanda, Client, Problema, Actiune,
Responsabil, Termen, Stadiu (Deschis / In lucru / Inchis), Prioritate (Normala /
Ridicata / Urgenta), Data inchidere, plus comentarii, fisiere atasate si istoric.
Obligatorii: Masina, Problema, Actiune, Responsabil.

INSTALARE
---------
1. Copiaza folderul pe calculatorul-server, intr-un folder LOCAL (ex. C:\GrindRingsTracker),
   nu in OneDrive / Desktop sincronizat. Daca il pornesti din OneDrive, instalarea se ofera
   sa il copieze singura in C:\GrindRingsTracker.
2. Dublu-click pe instalare-server.bat si accepta cererea de Administrator.
3. Creeaza contul de administrator (utilizator + parola): in instalare sau la prima
   deschidere a tracker-ului in browser - pagina il cere singura.
4. Gata - serverul porneste singur la fiecare pornire a calculatorului.
De proba, fara instalare: porneste-tracker.bat (merge cat timp fereastra e deschisa).


FOLOSIRE
--------
- Oricine din retea poate VEDEA tracker-ul. Ca sa adaugi sau sa modifici, apasa
  "Autentificare" si intra cu utilizatorul si parola ta.
- "Tine-ma minte pe acest calculator" (bifat implicit): browserul te autentifica automat
  180 de zile, pana apesi "Iesire". Nebifat: ramai autentificat pana inchizi browserul.
- Click pe o actiune: detalii, modificare, comentarii, fisiere atasate, istoric.
- Casutele de sus (Deschise, In lucru, Intarziate...) sunt si filtre: click pe ele.
- Export: descarca toate actiunile intr-un CSV care se deschide in Excel.


UTILIZATORI SI ROLURI
---------------------
- Primul cont creat este ADMINISTRATOR. Conturile se gestioneaza din Setari -> Conturi:
  cont nou (cu rol si email), parola noua, schimbare rol, dezactivare, stergere.
- Fiecare isi schimba numele, emailul si parola din Setari -> Contul meu.
- Ai uitat parola de administrator? editori.bat -> 2 = schimba parola (pe calculatorul-server).
- Parolele se pastreaza criptat (hash), niciodata in clar.

Roluri si drepturi implicite (se schimba din Setari -> Roluri, doar de Administrator):
  Administrator  - tot, inclusiv conturi, roluri si email
  Manager        - adauga, modifica orice, termen/prioritate, inchide, STERGE, comentarii, email
  Coordonator    - adauga, modifica orice, termen/prioritate, inchide, comentarii
  Zone Leader    - adauga, modifica si inchide doar actiunile PROPRII, comentarii
  Planificator   - adauga, schimba termenul si prioritatea la orice actiune, comentarii
"Proprii" = actiunile unde e responsabil (acelasi nume sau utilizator) sau pe care le-a creat.
Doar un Administrator poate numi alti administratori. Trebuie sa ramana mereu cel putin unul.
Fiecare vede in tracker doar butoanele si campurile pe care are voie sa le foloseasca.


IMPORT DIN EXCEL
----------------
Trage fisierul Excel peste import-excel.bat. Primul rand al foii trebuie sa contina
denumirile coloanelor; sunt recunoscute (cu sau fara diacritice):
  Nr, Data, Masina / Linie, Reper, Comanda, Client, Problema, Actiune, Responsabil,
  Termen, Stadiu, Prioritate, Data inchidere, Comentarii
Randurile cu un Nr care exista deja sunt sarite, deci importul se poate repeta.


MAILURI
-------
Totul se seteaza din tracker: Setari -> Email (doar administratorii).
1. Server de mail (SMTP): server, port, securitate, expeditor, utilizator si parola.
   Office 365: smtp.office365.com, port 587, STARTTLS. Intreaba IT-ul pentru serverul firmei.
2. Ce se trimite: fiecare responsabil primeste actiunile lui intarziate, cu termen in
   urmatoarele N zile sau urgente; "Rezumat catre" primeste lista completa. Rezumatul poate
   merge automat si la toti utilizatorii cu anumite roluri (ex. toti Managerii).
3. Destinatari: adresa fiecarui responsabil. Daca responsabilul are cont cu email
   (acelasi nume sau utilizator), adresa din cont se foloseste automat.
4. Trimitere automata: bifezi, alegi zilele si ora - serverul trimite singur.
5. "Trimite test", "Previzualizeaza" si "Trimite acum"; jurnalul arata ce s-a trimis.
Alternativ, prin Outlook: outlook-mailuri.bat (foloseste aceleasi setari si destinatari).


SIGURANTA DATELOR
-----------------
- Fiecare adaugare, modificare, comentariu, atasament si stergere apare in istoric
  (cine, cand, ce s-a schimbat).
- Backup zilnic in backups\. Restaurare: opreste serverul (reporneste-tracker.bat il
  porneste la loc), copiaza backup-ul peste grind_rings.db, porneste serverul.


ACTUALIZARE
-----------
Dezarhiveaza versiunea noua intr-un folder separat si ruleaza DE ACOLO actualizare-server.bat.
Se inlocuiesc doar fisierele programului; versiunea veche se pastreaza in backups\program_<data>.
